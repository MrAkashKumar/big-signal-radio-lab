## Definition of done

All four primary modes work without an account or backend. Lessons require a prediction, simulation, explanation, transfer check, and persist evidence. Every interactive RF control changes an engine input; unsupported phenomena are explicitly conceptual. Networks show bidirectional modeled links, isolated nodes, redundancy, energy, requirements, and weaknesses. A teacher can export a challenge and a learner can import and run it. Existing physics checks and new domain checks pass. Production browser checks verify the actual flows.

## Architecture choices

Candidate A composes a typed course registry with the current Scenario engine and a reusable lab workspace. Candidate B routes each lesson to a separate page/component with its own state. A is preferred because changes to simulation and persistence reach all lessons without duplicated controls. From B we retain distinct lesson phases and explicit observation/transfer state. The engine and curriculum owners independently check this against their concrete types before implementation.

# Build checklist

## Phase 0

- [x] Preserve the finalized build plan.
- [x] Document machine ownership and integration rules.
- [x] Create the planned directory layout.
- [x] Install TypeScript, React, Vite, Three.js, React Three Fiber, Zustand, and Vitest.
- [x] Add `dev`, `build`, `test`, and `test:physics` scripts.
- [ ] Agree on complete version 1 contracts.
- [x] Add deterministic mock simulation and example scenarios.
- [ ] Verify the build and tests from a clean install.
- [ ] Start both computers from the same tested bootstrap commit.

## Required demo

- [ ] Web app starts cleanly without a required cloud backend.
- [ ] Deterministic demo works offline after reload.
- [ ] VHF and HF missions work.
- [ ] Beginner and Advanced modes work.
- [ ] SEND IT animates the engine-provided path.
- [ ] Results show RX power, noise, SNR, link margin, success, and confidence.
- [ ] WHY explains limiting factors.
- [ ] MATH exposes calculations and assumptions.
- [ ] Prediction and attempt tracking work.
- [ ] Limiting factors rank potential improvement.
- [ ] POTATO mode and reset work.
- [ ] Unit tests and simulation validation pass.
- [ ] Core humor and branding support the lesson.
- [ ] Important visuals have accessible text and numbers.
- [ ] The actual demo machine maintains at least 30 FPS.
- [ ] Demo fixtures, expected results, and a backup recording exist.

## Stretch priority

Only begin after the required demo is stable. The ordered feature stretch list is microwave with Fresnel clearance, comparison, custom wire antennas, Crazy Lab, and mastery indicators. Add an Agents API tutor only after the simulator works. Voice is optional.
